# OpenCellComms: Constraining AI Coding Agents for Readable, Observable ABM Models

## Working thesis

OpenCellComms is a software environment for helping biologists build, observe,
validate, interrogate, modify, and share agent-based models (ABMs). It is designed
for a new situation: coding agents can now generate complex code quickly, but
biologists still need to understand what has been generated and how to change it.

The central idea is to guide and constrain coding agents so that generated ABM code
is not merely executable, but readable, navigable, validated, and organized around
biological concepts.
