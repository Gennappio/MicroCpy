# 7. AI-Guided Code Generation

OpenCellComms uses AI not as an unconstrained programmer but as a constrained model
author.

The AI receives a protocol: understand the model, fill the intake, create the
workflow skeleton, wait for preview approval, generate one node-function at a time,
validate, run, and review.

This matters because the output must be useful to a biologist. The goal is not to
generate the largest possible codebase. The goal is to generate code that is
readable, editable, explainable, and connected to the GUI.
