# 8.2 Parameters, Results, and Run Summary

OpenCellComms exposes parameters through nodes, rather than hiding them in code.
This allows biologists to adjust rates, thresholds, counts, and other values from
the GUI.

Runs should produce summaries that can be inspected after execution. A
machine-readable run summary can record cell counts, phenotype distributions,
resource statistics, health flags, and plot paths.

This makes review more systematic. The question is not only "did the simulation
finish?" but "did it produce the behavior expected in `MODEL.md`?"
