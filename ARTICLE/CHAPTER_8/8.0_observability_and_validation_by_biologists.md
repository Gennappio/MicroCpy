# 8. Observability and Validation by Biologists

A model is useful only if the biologist can observe and validate it.

OpenCellComms therefore treats outputs as part of the authoring loop. The model
should not only run; it should produce evidence that the run behaved as expected.
This evidence includes plots, summaries, logs, parameter values, and machine-readable
run summaries.

Observation closes the loop between the theoretical model, the generated workflow,
and the simulated behavior.
