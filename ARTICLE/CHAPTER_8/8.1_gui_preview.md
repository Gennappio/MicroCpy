# 8.1 GUI Preview

The GUI preview is an early validation step. Before Python functions are finalized,
the skeleton workflow can be opened and inspected.

The biologist can check:

- which agents exist;
- which resources exist;
- what happens during initialization;
- what happens each scheduler step;
- where outputs are produced;
- whether any obvious behavior is missing.

This preview reduces expensive iterations. It is easier to move a behavior from one
canvas to another before implementation details are written.
