# 2.1 Reduce Implicit Decisions

We observed that in AI-assisted software development the number of correction
iterations is strongly related to the number of design decisions the coding agent
must infer.

Informally:

```text
I ~ D
```

where `I` is the number of correction iterations and `D` is the number of implicit
design decisions.

In a conventional workflow, the biologist provides a biological description and the
coding agent must infer the architecture: scheduler, initialization, resources,
loops, outputs, data structures, and folder organization. Every inferred decision is
a possible wrong turn.

OpenCellComms reduces this decision space. The model is first translated into
explicit workflow slots: world, resources, agents, creation, behaviors, scheduler,
processing, and results. The coding agent then fills these slots instead of
inventing the structure.

This does not remove scientific uncertainty. The model can still have wrong
parameters or wrong biology. But it reduces avoidable software-structure
uncertainty, which is the source of many unproductive correction loops.
