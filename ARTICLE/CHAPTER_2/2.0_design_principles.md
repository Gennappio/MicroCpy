# 2. Design Principles

OpenCellComms is organized around a practical observation: most correction
iterations in AI-assisted modeling are not caused by Python syntax. They are caused
by missing or wrong architectural decisions.

The design therefore follows four principles:

1. Reduce implicit decisions.
2. Make the model visible to the biologist.
3. Constrain the coding agent.
4. Keep each biological operation small and inspectable.

These principles shape the GUI, the workflow JSON, the plugin structure, the
validator, and the prompts used to guide AI-assisted code generation.
