# 2.3 Constrain the Coding Agent

The coding agent is guided in three ways.

First, it is given an authoring protocol. It starts from a model intake, records
uncertainties, creates a workflow skeleton, waits for structure approval, and only
then generates Python code.

Second, it is given a target grammar. A biological process must be placed as a
World, Agent, Resource, Scheduler, Processing, or Result component. The agent has to
choose among known roles rather than invent a new architecture.

Third, it is given file and function conventions. Each node is a small Python file.
Each file has a defined role. Each role has an expected shape. An agent behavior
uses the bound `env.agent`. A collective creation function creates or wraps a
population. A resource behavior updates a field.

These constraints do not make the coding agent less useful. They make it safer. The
agent still writes code, but it writes code inside a structure that the biologist
can inspect and that the software can validate.
