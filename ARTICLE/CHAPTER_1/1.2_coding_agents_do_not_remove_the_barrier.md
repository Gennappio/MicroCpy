# 1.2 Coding Agents Do Not Remove the Barrier by Themselves

Large language models and coding agents make it easier to generate code. This is a
major opportunity for computational biology, because many useful models are delayed
or never built because writing the software is too costly.

However, generated code creates a new problem. A coding agent may produce many files
quickly, but a biologist still has to understand what was generated. If the generated
model is a monolithic script or an unconstrained folder of functions, the biologist
may not know:

- what biology is actually represented;
- which process happens before another;
- where to change a parameter;
- whether a function runs once or once per agent;
- where to inspect a signal or phenotype;
- whether the model is missing a step.

Coding agents are also not infallible. When information is missing, they often infer
instead of asking. In ABM construction, these inferred decisions are dangerous
because they define the architecture of the model. A plausible but wrong scheduler
or initialization order can change the meaning of the simulation.

Therefore, the key question is not simply "Can AI write ABM code?" The key question
is "How can we constrain AI-generated ABM code so that biologists can read, modify,
validate, interrogate, and share it?"
