# 1.3 The OpenCellComms Thesis

The thesis of OpenCellComms is that AI-assisted ABM authoring needs a constrained
intermediate representation, not just code generation.

OpenCellComms guides the coding agent through a small number of explicit model
objects:

- World;
- Agents;
- Resources;
- Initialization;
- Scheduler;
- Processing;
- Results.

The coding agent does not invent an architecture from scratch. It fills these
slots, writes atomic node-functions, and connects them through a workflow that the
GUI can display and the engine can execute.

This gives the biologist a model they can inspect at the level of the biology:
which agents exist, which resources exist, what each agent does, what each resource
does, what happens first, what happens every step, and what outputs are produced.

The goal is to reduce the number of correction iterations required to move from a
theoretical model to working code. The system does this by replacing implicit
decisions with explicit slots, by enforcing folder and node conventions, by
validating workflow semantics, and by asking the AI to generate one readable file
per biological operation.
