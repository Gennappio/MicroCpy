# 4.4 Reducing Correction Iterations

The purpose of the workflow IR is to reduce unnecessary correction rounds.

Without the IR, the loop often looks like this:

```text
Biologist describes model
        |
        v
Coding agent guesses architecture
        |
        v
Generated code
        |
        v
Run or inspection reveals hidden mistake
        |
        v
Biologist corrects the agent
```

With the IR, the loop becomes:

```text
Biologist describes model
        |
        v
Model slots are filled
        |
        v
Workflow is previewed and validated
        |
        v
Node code is generated
        |
        v
Run is reviewed against observables
```

The system does not guarantee biological correctness. It does not know whether a
rate, threshold, or hypothesis is scientifically right. But it reduces errors where
the agent guessed structure: missing creation, wrong ownership, hidden behaviors,
dead nodes, wrong loop shape, or invalid scheduling.

The desired result is that later iterations are about the biology rather than about
plumbing.
