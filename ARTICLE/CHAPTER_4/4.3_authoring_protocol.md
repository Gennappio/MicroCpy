# 4.3 The Authoring Protocol

The AI authoring process follows a protocol:

```text
Specification
      |
      v
Workflow IR
      |
      v
Preview
      |
      v
Node generation
      |
      v
Validation
      |
      v
Execution
      |
      v
Review
```

The protocol starts by asking for the model structure and sources. It records
unknowns instead of silently guessing them. It then creates a skeleton workflow for
review. Only after the structure is approved does the coding agent write Python
node-functions.

This is different from asking an LLM to write a simulator in one pass. The agent is
not rewarded for producing a large amount of code quickly. It is guided to produce a
small number of model objects that can be inspected before code is generated.

The protocol is also iterative in the right place. It invites the biologist to
correct the model structure before implementation details obscure the model.
