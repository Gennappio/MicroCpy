# 4.1 From MODEL.md to Workflow JSON

`MODEL.md` is the biological specification of record. It records what the model is
intended to represent, what sources were used, what assumptions were made, and what
observables should be checked after a run.

The workflow JSON is the executable structure derived from that specification. It
records the canvases, nodes, scheduler, initialization order, GUI ownership, and
parameters.

The transition from `MODEL.md` to workflow JSON is where the coding agent is most
constrained. The agent is asked to convert a biological description into explicit
slots:

- world;
- resources;
- agents;
- creation canvases;
- behavior canvases;
- scheduler order;
- initialization order;
- processing outputs.

The workflow JSON is then previewed in the GUI before Python function bodies are
finalized. This gives the biologist a chance to correct structure early.
