# 4.2 A Shared Language for GUI, Validator, Agent, and Runtime

The same workflow JSON is used by several components.

The GUI uses it to build tabs, canvases, nodes, parameter editors, overview diagrams,
and result links.

The validator uses it to check whether the model is structurally readable and
executable.

The coding agent uses it as a target. Instead of generating arbitrary code, the
agent fills missing functions and completes known nodes.

The runtime uses it as the execution plan. It follows `execution_order`, calls
subworkflows, expands per-agent asks, and passes the biological context into each
node.

This shared language is why the workflow IR reduces ambiguity. There is no separate
private representation for the GUI and another for execution. The object the
biologist sees is the object the engine runs.
