# 5.2 Creation, Behavior, Resource, and World Rules

The validator also checks the semantic role of major model components.

Agent creation is collective. It runs once and brings agents into existence. It must
not run with `for_each`, because that would repeat population creation once per
agent.

Agent behavior is per-agent. It runs through the scheduler's per-agent ask and acts
on the bound `env.agent`.

Resources are first-class model objects. A diffusing substance or signal should be
homed under its resource kind when the biologist should find it in the Resources tab.
World-level behavior is reserved for genuinely world-level or coupled operations.

Processing is for analysis and output. These nodes should not secretly change the
model's biological state after the simulation loop.

These rules make the model legible. A biologist looking for a chemokine opens
Resources. A biologist looking for a tumor-cell rule opens Agents. A biologist
looking for outputs opens Processing or Results.
