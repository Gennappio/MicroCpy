# 9.2 TCELL_CORRAL Case Skeleton

TCELL_CORRAL should illustrate immune-cell modeling and spatial signaling.

It can demonstrate:

- collective creation of cell populations;
- per-agent T cell behavior;
- supporting cell types;
- chemokine or signal fields;
- intracellular or state updates;
- spatial migration and interaction.

The chapter should emphasize that model complexity remains navigable because each
behavior is homed to a tab.

```text
World
  setup spatial domain

Resource
  chemokine
    initialize field
    diffuse / decay

Agents
  t_cell
    create cells
    step behavior
    update state
    migrate / interact

Scheduler
  ask T cells
  update signal
  reconcile
  report
```

Main message: OpenCellComms keeps a multi-agent immune model inspectable by
separating creation, per-agent behavior, resources, scheduler, and outputs.

Suggested figure: diagram of T cell behavior connected to chemokine resource field.
