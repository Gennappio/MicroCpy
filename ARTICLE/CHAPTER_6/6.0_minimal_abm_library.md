# 6. Minimal ABM Library

OpenCellComms includes a small ABM library that provides the basic objects used by
node-functions. The library is intentionally minimal. It is not meant to hide the
model in a large framework. It provides stable objects that workflow nodes can call.

The main objects are:

- World;
- Agent;
- Population;
- Resource;
- Domain;
- intents and reconciliation.

This gives generated functions a common vocabulary. Instead of each coding agent
inventing its own cell and field abstractions, node-functions use the same typed
environment.
