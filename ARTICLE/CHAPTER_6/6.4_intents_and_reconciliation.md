# 6.4 Intents and Reconciliation

ABM behavior often changes shared state: cells move, divide, die, consume resources,
or secrete substances. If every agent directly changes shared state immediately,
execution order can create accidental artifacts.

OpenCellComms supports an intent-and-reconciliation pattern. Agent behaviors can
request actions, such as movement, resource consumption, secretion, birth, or death.
A reconciliation step later commits these requests in a controlled place.

This makes the scheduler easier to understand. Agent behaviors decide what agents
want to do. Reconciliation applies those decisions. The separation is useful for
both validation and biological interpretation.
