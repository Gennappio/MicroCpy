# 3. Software Organization

OpenCellComms separates reusable model code from experimental arrangements.

The main distinction is:

- a plugin is a library of model-specific functions and behaviors;
- a workflow is an experiment that arranges those functions in a particular order
  with particular parameters.

This separation is important for biological modeling. The same functions can be
used in multiple workflows. For example, a tumor-cell oxygen-consumption function
can appear in a baseline experiment, a hypoxia experiment, and a perturbation
experiment. The function is the reusable biological operation. The workflow is the
experimental design.
